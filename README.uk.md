# Rehab Copilot

ШІ-асистент фізичного терапевта: від збору анамнезу
до діагностичних гіпотез і планування реабілітації.
[English](README.md) | Українська

## Ідея проєкту

Rehab Copilot розробляється як помічник фізичного терапевта
під час обстеження людини зі скаргами з боку
опорно-рухового апарату.

Застосунок має допомагати збирати анамнез, уточнювати скарги,
обирати функціональні тести, аналізувати результати та
обґрунтовувати діагностичні гіпотези.

На основі зібраної інформації асистент пропонуватиме
відповідні клінічні рекомендації, протоколи за їх наявності
та чернетку плану реабілітації з посиланнями на джерела.

## Для кого

Для фізичних терапевтів і студентів фізичної терапії,
які хочуть використовувати структурований підхід
до обстеження та клінічного міркування.

## Запланований сценарій роботи

1. Спеціаліст створює випадок і вводить скарги, анамнез
   та цілі людини.
2. Асистент пропонує уточнювальні питання та вказує,
   якої інформації бракує.
3. Асистент позначає потенційні ознаки, що потребують
   медичного направлення.
4. Асистент пропонує функціональні тести та вимірювання,
   пояснюючи їхнє призначення й обмеження.
5. Спеціаліст обирає обстеження та вводить результати.
6. Асистент формує діагностичні гіпотези з аргументами,
   невизначеністю та питаннями для подальшої перевірки.
7. Асистент пропонує лікувальні й реабілітаційні підходи
   для розгляду спеціалістом у межах його компетенції.
8. Спеціаліст перевіряє джерела, редагує та затверджує
   підсумковий план.

## Перший реліз

Перший завершений сценарій — первинне обстеження
дорослого з болем у попереку.

Планується два режими:

- AI mode — відповіді мовної моделі з пошуком
  у відібраних джерелах.
- Demo mode — заздалегідь підготовлені, чітко позначені
  відповіді без потреби в платному API.

Підтримка інших ділянок опорно-рухового апарату
додаватиметься поступово.

## Межі застосування

Rehab Copilot допомагає формувати та перевіряти припущення.
Він не встановлює остаточний діагноз і не призначає
лікування автономно.

Відповіді та посилання ШІ потребують перевірки.
Відсутність попередження не гарантує відсутності ризику.

## Запланований стек

- Node.js + TypeScript — основний сервер та API.
- Python — інтеграція ШІ, RAG та оцінювання відповідей.
- HTML/CSS/JavaScript — вебінтерфейс.
- SQLite — зберігання випадків.
- Rust — розрахунок динаміки показників болю та функції.
- GitHub Actions — автоматичні перевірки.
- Docker — відтворюваний запуск.
